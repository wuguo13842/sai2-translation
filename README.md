# SAI2 汉化文本开源库

> ⚠️ 本仓库仅包含纯文本翻译词库与自动化脚本，**不提供任何现成的汉化 EXE 成品**。

## 📖 关于本项目
这是由个人业余时间整理的 SAI2 英文界面全量翻译词库。

为了确保术语符合绘画习惯，翻译底稿并非直接机翻，而是**结合了英文界面与日文原版进行交叉比对，并逐行进行了纯人工的矫正与润色**，力求原汁原味。

底层方案采用纯静态替换逻辑，解决“同词多义”问题。生成程序绝对干净，无任何运行库依赖。

> 📌 **版本对应说明**：SAI2 每次官方更新，内部字符串地址都会变动。最新词库对应 `20261019` 版本，请优先使用对应日期的映射表。

## 🤝 如何协助校对？
如果你发现软件内翻译有误或不够地道，**请点击上方的 [Issues] -> [New Issue]** 选择“翻译纠错/优化”。

⚠️ **提 Issue 硬性要求：**
1. **必须附带软件界面的截图**。
2. **必须说明该功能在哪个菜单/面板下**（如：画笔设置 -> 混色 -> 水分量）。
3. 说明你建议改成什么。
*(因为软件内同一个词在不同界面的意思完全不同，没有截图我实在无法定位，可能就直接关了，见谅。)*

## 🧰 开发者工具链
本仓库同时开源了全套底层处理脚本：
* `scripts/`：核心静态替换脚本（含 PE 解析、自动寻找内存空洞、指针重定向）。
* `tools/`：全量文本提取、乱码清洗、地址反查、长句提取等辅助工具。
* `build.py`：一键打包脚本（放入 `new.exe` 即可运行生成 `sai2.exe`）。
